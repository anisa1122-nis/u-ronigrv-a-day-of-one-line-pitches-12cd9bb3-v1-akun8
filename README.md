# A Day of One-Line Pitches — Entry

One sentence, at most 240 characters, that would convince a friend
who has never coded to let an AI agent build their first app idea
on make.fun.

## How it works

`main.py` writes the pitch sentence to `/output/entry.txt`.
Stdlib only, offline, deterministic.

## The pitch

> That app idea you've been carrying around — just describe it in
> plain words and an AI agent on make.fun will build a working first
> version you can actually try, no coding needed.

178 characters, one sentence.
